# 裸辞模拟器 MVP

> 用 10 分钟，替你活一遍裸辞之后的那一年。

**交付文件：`裸辞模拟器.html`（单文件，样式和脚本全部内联）——双击即可玩，发给别人也能直接打开，不依赖任何外部文件。**

开发期用 `index.html` + `css/` + `js/` 分文件维护，改完执行 `node build.js` 重新生成单文件版。

## 界面（新版）

- 小红书测评类 H5 风格：奶油暖色底、大圆角卡片、粗圆按钮、书卷体标题
- 年龄 / 月薪 / 存款：**直接输入数字 + 加减按钮**（滑动条已废弃）
- 性别、住房、家庭、城市：分段按钮选择，新增性别选项（影响开场白人称）
- 月度推演带 12 格进度点阵，结局页人格卡强调"复合人格"稀有感

## 玩法结构

1. **开局设定**（6 项：年龄/月薪/存款/住房/家庭/城市）→ 自动算出每月刚性支出和"存款能撑几个月"
2. **按月推演** ×12：每月 1 个随机事件（有选择的做选择）→ 选本月主策略（投简历 / 接零活 / 学习充电 / 躺平休整）→ 月末结算
3. **结局**：翻身线 / 回归线 / 转型线 / 崩盘线 / 迷雾线
4. **裸辞人格**（六型 + 复合人格）：由整局决策序列判定，不由结局判定
5. **结局卡**：canvas 生成 1080×1440 PNG，一键保存，适合发小红书/朋友圈
6. **分享回流**：结局页「用我的人设拉朋友进来」生成带参数的链接，朋友进来继承同样人设、走不同人生


## 数值引擎要点（v1 定稿）

- 月支出 = 住房（一线房租 5000 / 新一线 3200 / 老家 1500，或房贷=月薪×45%）+ 生活成本 × 家庭系数（单身 1.0 / 伴侣 1.25 / 有娃 1.7）
- 心态：开局 82，辞职新鲜感 1-2 月 +4，躺平 +4 且第 4 个月起衰减，存款 < 3 个月支出每月 -6，被拒 -6，emo 事件 <20 触发
- 竞争力：开局 100，纯空窗 -3/月，学习 +4，零活 -1，求职期 -1
- offer：单次面试成功率 = 5% + (竞争力-50)/200，封顶 40%；35 岁以上 -5pp；内推 +15pp、风口 +20pp 可叠加
- 结局阈值：新薪 ≥ 原薪×1.1 → 翻身线；全额崩盘（存款≤0 或心态≤0，且手上无 offer）→ 崩盘线；满 12 月仍空窗 → 迷雾线

**架构原则：数值引擎纯规则、确定、可复现；LLM 只负责开场白/结局金句等文采层，不碰数值。**

## 接入 LLM（可选）

编辑 `js/config.js` 中 `llm` 段（任何 OpenAI 兼容接口）：

```js
llm: { enabled: true, url: 'https://…/chat/completions', apiKey: '…', model: '…', timeoutMs: 6000 }
```

未配置时自动降级为模板文案，功能完整可玩。若在浏览器直接打开（file://）且 LLM 接口不支持跨域，请勿开启——模板模式即默认形态。
